# Chojema CopyKeep

[English](README.en.md) | [다운로드](https://github.com/chojema/ChojemaCopyKeep/releases/latest)

텍스트와 이미지의 복사 기록을 저장하고, 단축키로 불러와 붙여넣는 Windows 및 macOS용 클립보드 관리 앱입니다.

## 다운로드 및 실행

Windows와 macOS 배포 파일은 같은 [최신 릴리스 페이지](https://github.com/chojema/ChojemaCopyKeep/releases/latest)에서 제공합니다.

Windows 10과 Windows 11의 x64 환경을 대상으로 합니다. 관리자 권한 없이 다음 두 방식 중 하나로 사용합니다.

| 배포 방식 | 파일 | 사용 방법 |
| --- | --- | --- |
| 설치형 | `ChojemaCopyKeep-windows-x64-setup-0.4.0.exe` | 설치 후 시작 메뉴에서 실행합니다. Windows 설정의 설치된 앱에서 제거할 수 있습니다. |
| 단독 실행형 | `ChojemaCopyKeep-windows-x64-portable-0.4.0.zip` | 압축을 풀고 `ChojemaCopyKeep.exe`를 실행합니다. 설치와 제거 등록이 없습니다. |

설치형의 기본 위치는 `%LOCALAPPDATA%\Programs\ChojemaCopyKeep`입니다. 설치, 업데이트 또는 제거 전에는 알림 영역 메뉴에서 실행 중인 앱을 종료해야 합니다. 단독 실행형으로 새 버전을 실행할 때도 기존 앱을 먼저 종료하세요. 두 방식은 동시에 실행되지 않으며, 기존 앱이 실행 중이면 새 실행 파일은 종료됩니다.

두 방식 모두 `%LOCALAPPDATA%\ChojemaCopyKeep\history.db`에 기록, 상용구와 설정을 저장하므로 전환 후에도 데이터를 이어서 사용합니다. 단독 실행형도 데이터를 실행 파일 옆에 저장하지 않습니다. 설치형을 제거하거나 단독 실행형 폴더를 삭제해도 이 데이터는 남습니다. 설치형은 기존 로그인 자동 실행이 켜져 있으면 바로 가기를 새 설치 위치로 갱신하며, 기본으로 자동 실행을 켜지 않습니다. 제거 시에는 해당 설치본을 가리키는 자동 실행 바로 가기만 삭제합니다.

`SHA256SUMS-windows.txt`에서 두 Windows 파일의 SHA-256을 확인할 수 있습니다. 기존 Windows ZIP과 체크섬도 보존합니다. Windows 실행 파일과 설치 프로그램에는 코드 서명이 없습니다. 실행 상태는 알림 영역 아이콘으로 확인합니다.

macOS 13 이상에서는 [최신 릴리스](https://github.com/chojema/ChojemaCopyKeep/releases/latest)의 macOS Universal ZIP을 풀고 `Chojema CopyKeep.app`을 응용 프로그램 폴더로 옮겨 실행합니다. Apple Silicon과 Intel 실행 파일을 함께 포함합니다. 실행 상태와 설정은 메뉴 막대의 클립보드 아이콘에서 확인합니다. 이 배포물은 임시 서명(ad hoc)을 사용하며 Developer ID 서명과 Apple 공증을 포함하지 않습니다. macOS가 실행을 차단하면 시스템 설정 > 개인정보 보호 및 보안에서 해당 앱의 실행을 허용해야 할 수 있습니다.

## 사용 방법

1. 다른 앱에서 텍스트 또는 이미지를 복사합니다.
2. 붙여넣을 입력 위치에서 `Ctrl + Shift + Z`를 누릅니다.
3. 바로 `Enter`를 누르면 첫 번째 항목을 붙여넣습니다. 방향키나 마우스로 다른 항목을 선택할 수도 있습니다.
4. `Esc`를 누르면 목록이 닫힙니다.

목록은 입력 커서 오른쪽 근처에 표시됩니다. 커서 위치를 확인할 수 없으면 마우스 포인터 근처에 표시됩니다. 기록은 앱 실행 이후 복사한 내용부터 저장됩니다.

짧은 텍스트는 목록만 표시합니다. 목록 한 줄에 담기지 않는 텍스트, 여러 줄 텍스트 또는 이미지를 선택하면 오른쪽에 미리보기가 자동으로 나타납니다. 짧은 항목을 선택하면 다시 목록만 표시하며, 미리보기를 여는 별도 조작은 필요하지 않습니다.

마우스 포인터를 항목 위에 잠시 올려 두면 선택을 바꾸지 않고 그 항목의 미리보기를 표시합니다. 포인터가 목록을 벗어나면 선택한 항목의 미리보기로 돌아갑니다. 항목을 클릭하면 바로 붙여넣습니다.

목록은 문서 또는 그림 아이콘과 복사 내용을 한 줄에 표시합니다. 선택한 항목은 배경색과 윤곽으로 강조하며, 아래쪽에서 붙여넣기 키 안내와 설정 및 삭제 버튼을 사용할 수 있습니다.

알림 영역 아이콘을 마우스 오른쪽 버튼으로 클릭하면 설정, 수집 일시 중지, 종료 메뉴를 사용할 수 있습니다.

macOS에서도 기본 호출 단축키는 `Control + Shift + Z`입니다. 메뉴 막대 아이콘을 클릭해 설정, 수집 일시 중지와 종료 메뉴를 엽니다. 원래 앱에 붙여넣으려면 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 Chojema CopyKeep을 허용해야 합니다. 권한이 없으면 앱이 안내하며 붙여넣기 입력을 보내지 않습니다.

## 설정 및 기록 관리

- 기본 언어는 한국어입니다. 영어로 전환하면 즉시 반영되며 설정을 저장하면 다음 실행에도 유지됩니다.
- 단축키는 Ctrl 또는 Alt를 포함한 조합으로 변경할 수 있습니다. 기본값은 `Ctrl + Shift + Z`입니다.
- macOS에서는 Control, Option 또는 Command와 문자·숫자 키를 조합하고 Shift를 추가할 수 있습니다. 단축키 문자는 미국식 키보드의 물리 키 위치를 기준으로 합니다.
- 사용한 항목을 맨 위로 이동하는 옵션은 기본으로 켜져 있습니다.
- 로그인 자동 실행은 기본으로 꺼져 있으며 설정에서 선택합니다.
- 보관 개수는 기본 200개이며 10~1000개로 조정합니다. 중복 내용은 하나로 합쳐 최근 순서로 이동합니다.
- 목록에서 Delete 키 또는 삭제 버튼으로 선택 항목을 삭제하고, 전체 삭제는 확인 후 실행합니다.

저장 한도는 항목당 32 MiB, 이미지당 16,777,216픽셀, 저장된 원문 합계 256 MiB입니다. 데이터베이스 파일 크기와 프로세스 메모리 사용량은 별도로 달라질 수 있습니다.

## 업데이트 확인

Windows 알림 영역 아이콘을 마우스 오른쪽 버튼으로 클릭하거나 macOS 메뉴 막대 아이콘을 클릭하고 `업데이트 확인`을 선택합니다. 확인은 백그라운드에서 진행하며 현재 버전과 최신 정식 버전을 안내합니다. 새 버전이 있으면 확인 후 공식 릴리스 페이지를 브라우저로 엽니다. 다운로드와 설치는 직접 진행하며, 앱을 종료한 뒤 설치하거나 새 ZIP의 압축을 풀어 실행합니다. 기록과 설정은 기존 저장 위치에 유지됩니다.

업데이트 확인은 사용자가 메뉴를 선택할 때만 GitHub에 접속합니다. 연결 실패는 별도로 안내하며 최신 버전이라고 표시하지 않습니다. 이 기능은 Windows와 macOS 0.3.0부터 제공됩니다. macOS에서는 앱을 종료한 뒤 압축을 푼 새 앱으로 응용 프로그램의 기존 앱을 교체합니다.

## 텍스트 대치

Windows와 macOS 0.4.0부터 약어를 입력하면 등록한 문구로 자동으로 바꿉니다. 예를 들어 `;;addr`에 여러 줄의 주소를 등록하면, 다른 앱에서 `;;addr`의 마지막 글자를 입력하고 키를 놓을 때 주소로 대치됩니다. 팝업을 열 필요가 없습니다.

- 메뉴나 팝업에서 `텍스트 대치`를 열고 `새 텍스트 대치`를 선택합니다. 제목, 약어와 입력할 내용을 등록합니다. 내용은 여러 줄·한글·이모지를 포함하여 65,536자까지 지원합니다(보조 문자는 두 글자로 계산될 수 있습니다).
- 약어는 공백 없는 영문·숫자·기호 2~64자이며 대소문자를 구분합니다. 중복 약어와 서로의 접두어인 약어는 등록할 수 없습니다. 일반 단어와 겹치지 않도록 `;;addr`, `;;sig`처럼 지정하세요. 영문·숫자로 시작하는 약어는 단어 중간에서 대치하지 않습니다.
- **약어는 영문 입력 상태에서 입력합니다.** 한글 조합 중인 입력은 대치하지 않습니다. 대치할 내용에는 한글을 자유롭게 사용할 수 있습니다.
- 기존 상용구는 그대로 보존됩니다. 약어를 추가하면 자동 대치에 사용할 수 있고, 약어를 비워 두면 목록에서 선택해 붙여넣는 방식으로 사용할 수 있습니다. 제목·내용·약어 검색, 편집, 기록에서 저장, 확인 후 개별 삭제를 제공합니다.
- 기록의 보관 한도와 전체 삭제는 텍스트 대치 항목에 영향을 주지 않습니다. 메뉴의 일시 중지는 기록 수집과 자동 대치를 함께 멈춥니다.
- macOS에서는 손쉬운 사용 권한이 필요합니다. 앱의 권한 안내에 따라 허용한 뒤 재실행하세요. 암호 입력란과 보안 입력 모드는 제외합니다. 현재 입력란의 커서와 약어를 접근성 API로 확인할 수 없는 앱에서는 원문을 유지하고 대치하지 않습니다. Windows에서는 관리자 권한으로 실행한 앱 등에 입력이 제한될 수 있습니다.
- 대치 시 등록한 문구를 시스템 클립보드에 복사하고 붙여넣습니다. 기존 클립보드 내용은 바뀌며, 대치 결과 자체는 복사 기록에 자동 저장하지 않습니다. 날짜 변수와 스크립트 실행은 제공하지 않습니다.

## 데이터 저장 및 개인정보

기록과 설정은 `%LOCALAPPDATA%\ChojemaCopyKeep\history.db`에 저장됩니다. 클립보드 내용의 원격 전송, 클라우드 동기화, 계정 로그인, 사용량 수집 기능은 없습니다. 업데이트 확인을 실행하면 GitHub에 접속하며 기록·상용구·설정은 전송하지 않습니다. 데이터베이스에 앱 자체 암호화는 적용되지 않습니다.

macOS의 저장 위치는 `~/Library/Application Support/ChojemaCopyKeep/history.db`입니다. 두 운영체제의 기록은 독립적으로 보관됩니다.

민감한 복사 내용도 저장될 수 있습니다. 수집 제외 범위와 일시 중지, 삭제 기능은 [개인정보 안내](docs/PRIVACY.ko.md)에 설명되어 있습니다.

## 지원 범위 및 제한

- 텍스트는 일반 텍스트로 저장합니다. HTML, RTF, 파일 복사, 여러 항목을 묶은 클립보드 형식은 지원하지 않습니다.
- 이미지는 Windows에서 PNG와 비트맵, macOS에서 PNG와 TIFF 형식을 수집합니다. 붙여넣을 앱도 이미지 입력을 지원해야 합니다.
- 붙여넣기는 원래 앱에 `Ctrl + V` 입력을 전송하는 방식입니다. 대상 앱의 입력 제한에 따라 동작하지 않을 수 있으며, 관리자 권한 앱과 보안 입력 화면에서는 제한될 수 있습니다.
- 앱별 붙여넣기 호환성과 장시간 실행 동작은 추가 검증이 필요합니다.
- macOS는 원래 앱으로 전환한 뒤 `Command + V` 입력을 전송합니다. 보안 입력이나 대상 앱의 제한에 따라 동작하지 않을 수 있으며 입력 전송이 내용 수용을 보장하지는 않습니다.
- macOS 0.2.0는 Apple Silicon에서 합성 데이터 검사와 화면 렌더링을 검증했습니다. Intel에서는 빌드와 실행 파일 구성을 확인했으며 실제 Intel 하드웨어, 외부 앱별 붙여넣기와 로그인 후 자동 실행은 미검증입니다.

## 소스 빌드

Visual Studio C++ 데스크톱 개발 도구, Windows SDK, CMake, Ninja가 필요합니다. 환경 구성과 검사 방법은 [빌드 안내](docs/BUILD.ko.md)에 정리되어 있습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1 -Test
```

빌드 결과는 `build/windows/ChojemaCopyKeep.exe`에 생성됩니다.

macOS에서는 Xcode Command Line Tools의 Swift 6.0 이상을 사용합니다. 외부 패키지는 필요하지 않습니다.

```bash
bash tools/build-macos.sh test
bash tools/build-macos.sh universal
bash tools/package-macos.sh
```

앱은 `build/macos/Chojema CopyKeep.app`, 배포 ZIP은 `dist/macos-v0.4.0/`에 생성됩니다. Windows와 macOS 0.4.0 소스는 공통 `v0.4.0` 태그를 사용합니다.
