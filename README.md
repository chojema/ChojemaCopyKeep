# Chojema CopyKeep

[English](README.en.md)

텍스트와 이미지를 보관하고 단축키로 골라 붙여넣는 Windows용 클립보드 기록 앱입니다. 제작자는 Park Chulwoo입니다.

## 실행

Windows 10 또는 Windows 11의 x64 환경을 대상으로 합니다. `ChojemaCopyKeep.exe`를 실행하면 알림 영역에 아이콘이 표시됩니다. 관리자 권한은 필요하지 않습니다.

1. 다른 앱에서 텍스트 또는 이미지를 복사합니다.
2. 붙여넣을 입력 위치에서 `Ctrl + Shift + Z`를 누릅니다.
3. 바로 `Enter`를 누르면 첫 번째 항목을 붙여넣습니다. 방향키나 마우스로 다른 항목을 선택할 수도 있습니다.
4. `Esc`로 목록을 닫습니다. 알림 영역 아이콘의 오른쪽 메뉴에서 수집 일시 중지와 종료를 선택할 수 있습니다.

목록은 입력 커서 근처에 표시하며 위치를 확인하지 못하면 마우스 포인터 근처에 표시합니다. 기록은 앱 실행 이후의 복사부터 수집합니다.

## 설정

- 최초 언어는 한국어입니다. 설정에서 English로 전환하면 즉시 적용되고 저장 후 재실행에도 유지됩니다.
- 단축키는 Ctrl 또는 Alt를 포함한 조합으로 변경할 수 있습니다. 기본값은 `Ctrl + Shift + Z`입니다.
- 사용한 항목을 맨 위로 이동하는 옵션은 기본으로 켜져 있습니다.
- 로그인 자동 실행은 기본으로 꺼져 있으며 설정에서 선택합니다.
- 보관 개수는 기본 200개이며 10~1000개로 조정합니다. 중복 내용은 하나로 합쳐 최근 순서로 이동합니다.
- 항목당 최대 32 MiB, 이미지 최대 16,777,216픽셀, 저장된 원문 합계 최대 256 MiB를 적용합니다. 전체 데이터베이스 파일 크기와 프로세스 메모리를 의미하는 수치는 아닙니다.
- 목록에서 Delete 키 또는 삭제 버튼으로 선택 항목을 삭제하고, 전체 삭제는 확인 후 실행합니다.

## 저장과 개인정보

기록과 설정은 `%LOCALAPPDATA%\ChojemaCopyKeep\history.db`에 저장합니다. 전체 기록을 메모리에 상주시켜 두지 않으며 이미지 미리보기는 선택할 때 만듭니다. 클라우드 동기화, 계정 로그인, 원격 콘텐츠 전송과 사용량 수집 기능은 없습니다. 데이터베이스는 앱 자체에서 암호화하지 않습니다.

복사한 민감한 내용도 기록에 포함될 수 있습니다. 수집 일시 중지와 삭제 기능을 사용하세요. 앱에서 제외 표시를 제공하는 클립보드 항목은 수집하지 않지만 모든 앱의 민감 정보를 자동 판별하지는 않습니다. 자세한 내용은 [개인정보 안내](docs/PRIVACY.ko.md)를 참고하세요.

## 지원 범위

- 텍스트는 일반 텍스트로 보관합니다. HTML, RTF, 파일 복사와 여러 항목을 묶은 형식은 현재 지원 범위가 아닙니다.
- 이미지는 PNG와 Windows 비트맵을 대상으로 합니다. 이미지를 붙여넣을 수 있는 입력 대상이 필요합니다.
- 붙여넣기는 원래 앱에 Ctrl + V 입력을 보내는 방식입니다. 관리자 권한 앱과 보안 입력 화면에서는 제한될 수 있습니다. 입력 전송 성공만으로 대상 앱이 붙여넣기를 받아들였음을 보장하지는 않습니다.
- macOS 버전은 아직 구현하지 않았습니다. 추후 별도로 개발하고 빌드합니다.

## 빌드와 검사

[한국어 빌드 안내](docs/BUILD.ko.md)를 참고하세요. Visual Studio의 C++ 데스크톱 개발 도구, Windows SDK, CMake와 Ninja가 필요합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1 -Test
```

실행 파일은 `build/windows/ChojemaCopyKeep.exe`입니다. 개발 중인 0.1.0 버전이며 앱별 실제 붙여넣기 호환성과 장시간 실행 검증은 별도로 진행해야 합니다.
