# 개인정보와 로컬 저장

[English](PRIVACY.en.md) | [README](../README.md)

## 수집과 보관

앱 실행 중 복사한 텍스트와 이미지를 로컬 데이터베이스에 저장합니다. 원본 앱의 이름, 창 제목, 전체 키 입력은 기록하지 않습니다. 실행 전에 클립보드에 있던 내용은 자동으로 가져오지 않습니다.

기록과 설정은 `%LOCALAPPDATA%\ChojemaCopyKeep\history.db`에 저장됩니다. 개발용 저장 폴더를 지정한 경우 해당 위치를 사용합니다. 앱 자체 암호화는 적용되지 않으며 저장 파일의 접근은 Windows 계정과 폴더 권한으로 관리됩니다.

macOS에서는 `~/Library/Application Support/ChojemaCopyKeep/history.db`에 저장하며 macOS 계정과 폴더 권한으로 접근을 관리합니다. 폴더는 해당 계정만 접근하도록, 데이터베이스는 해당 계정만 읽고 쓰도록 생성합니다. 두 운영체제 모두 SQLite 임시 기록 파일을 같은 폴더에 만들 수 있습니다.

macOS 0.2.0과 Windows 소스 빌드에서 사용자가 등록한 상용구도 같은 데이터베이스에 저장됩니다. 상용구는 복사 기록과 별도로 보관하므로 기록 전체 삭제나 보관 한도로 삭제되지 않으며, 상용구 목록에서 개별 삭제해야 합니다. 상용구도 자체 암호화하지 않습니다.

## 전송

앱에는 클립보드 내용 전송, 계정 로그인, 클라우드 동기화, 사용량 수집, 자동 업데이트 기능이 없습니다. GitHub 저장소와 릴리스에는 소스와 배포 파일만 게시합니다.

## 수집 일시 중지 및 삭제

알림 영역 메뉴에서 수집을 일시 중지할 수 있습니다. 기록은 개별 삭제하거나 확인 후 전체 삭제할 수 있습니다. 전체 삭제는 앱에 저장된 기록에 적용되며, 현재 시스템 클립보드와 다른 앱에 붙여넣은 내용은 유지됩니다. 저장 매체의 데이터 완전 삭제는 보장하지 않습니다.

원본 앱이 클립보드에 수집 제외 표시를 제공하면 해당 항목을 건너뜁니다. 비밀번호나 개인정보를 내용만으로 자동 판별하지는 않습니다. 민감한 내용을 복사하기 전 수집을 일시 중지할 수 있습니다.

macOS는 ConcealedType, TransientType, AutoGeneratedType 및 1Password 표시와 파일 URL을 건너뜁니다. 0.5초 간격으로 클립보드 변경을 확인하므로 매우 빠르게 연속 복사하면 중간 항목을 놓칠 수 있습니다. 손쉬운 사용 권한은 입력 커서의 위치 확인과 원래 앱에 붙여넣기 단축키 전송에 사용하며, 일반 키 입력을 감시하거나 기록하지 않습니다. 권한이 없어도 클립보드 수집은 동작합니다.

## 개발과 공개

저장 데이터, 개인 설정, 인증 정보, 로그, 내부 작업 기록, 개인 이메일과 경로는 공개 저장소 및 배포물에서 제외합니다. 공개 이슈나 화면 캡처에도 실제 복사 내용이 드러나지 않도록 합성 샘플을 사용합니다.
