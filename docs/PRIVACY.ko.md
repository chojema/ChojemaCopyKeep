# 개인정보와 로컬 저장

[English](PRIVACY.en.md) / [처음으로](../README.md)

제작자: Park Chulwoo

## 수집과 보관

실행 중 클립보드가 변경되면 지원되는 텍스트 또는 이미지를 로컬 데이터베이스에 보관합니다. 원본 앱의 이름, 창 제목과 입력한 키 전체를 기록하지 않습니다. 프로그램을 시작하기 전에 있던 클립보드 내용은 자동으로 가져오지 않습니다.

기록과 설정은 `%LOCALAPPDATA%\ChojemaCopyKeep\history.db`에 저장합니다. 별도 개발 저장 폴더를 지정했다면 해당 폴더를 사용합니다. 앱 자체 암호화는 적용하지 않습니다. 장치 계정과 파일 접근 권한을 통해 저장 폴더를 관리해야 합니다.

## 전송

앱에는 복사 내용을 서버로 전송하는 기능, 계정 서비스, 클라우드 동기화, 원격 측정과 자동 업데이트가 없습니다. GitHub는 소스와 배포물을 관리하는 용도이며 실제 복사 기록을 올리는 용도가 아닙니다.

## 제어

알림 영역 메뉴에서 수집을 일시 중지할 수 있습니다. 저장된 기록은 개별 삭제 또는 확인 후 전체 삭제할 수 있습니다. 앱의 전체 삭제는 현재 시스템 클립보드를 지우거나 대상 앱에 이미 붙여넣은 내용을 삭제하지 않습니다. 파일의 물리적 완전 삭제를 보장하는 기능은 아닙니다.

클립보드에서 제외 표시를 제공하는 일부 앱의 내용은 건너뜁니다. 모든 비밀번호나 개인정보를 자동 식별하는 기능은 아니므로 민감한 내용을 복사할 때는 수집을 일시 중지하세요.

## 개발과 공개

저장 데이터, 개인 설정, 인증 정보, 로그, 내부 작업 기록, 개인 이메일과 경로는 공개 저장소 및 배포물에서 제외합니다. 공개 이슈나 화면 캡처에도 실제 복사 내용이 드러나지 않도록 합성 샘플을 사용합니다.
